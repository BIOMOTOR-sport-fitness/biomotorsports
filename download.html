📲 Install on iPhone / iPad

  1. Open this page in Safari.
  2. Tap the Share button (square with ↑ arrow).
  3. Tap Add to Home Screen, then Add.
The BIOMOTOR icon appears on your Home Screen and opens full-screen.

📱 Android APK — first time only

  1. Tap Download APK file.
  2. Open the downloaded file.
  3. If asked, allow Install unknown apps for your browser, then tap Install.
Easiest way: tap Install on Android above — Chrome installs the app directly, and it updates by itself.

🖥️ Windows & 💻 Mac — first time only

  1. Windows: open BIOMOTOR-Windows-Setup.exe. If SmartScreen appears, click More info → Run anyway.
  2. Mac: open BIOMOTOR-Mac.dmg, drag BIOMOTOR to Applications. First launch: right-click → Open.
  3. Or use Install from browser in Chrome / Edge — no file needed.
